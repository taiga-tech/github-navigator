## 注記

各タスクは以下の原則に従って実装する:

- **テスト駆動開発**: 実装前に必ずテストを作成
- **段階的構築**: 前のタスクの出力を明確に使用
- **要件トレーサビリティ**: 各タスクは特定のREQ番号にマップ
- **パフォーマンス重視**: 300ms表示、2秒API応答、1MB未満バンドルを維持
- **型安全性**: TypeScript とzod を使用した厳密な型チェック
- **エラーハンドリング**: 全機能でエラー状態とリトライ処理を実装
